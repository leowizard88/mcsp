title: "Quando tornerà l’età del ferro"

tipo: "poesia"

Quando tornerà l’età del ferro /
E saremo tutti /
Nere formiche /
Tornerà il mio spettro a scrivere /
Le stesse parole /
Che ho appena scritto. /

Quando tornerà l’età del ferro /
Sarà tutto più basso /
E affiggere poesie /
O un carcere letterario /
Di progetti politici /
Di Volpi bipedi /
Di fili di sangue /
Fatte di sale /
Che sono centauri /
Che trattano al bar /
Di un futuro imminente /
Lasciati in pasto /
Ad un granello nevrotico /
Saranno grandi /
Le messe vuote /
Perché bipedi volpi /
Aspetteranno l’oro /
Dell’età del ferro. /
